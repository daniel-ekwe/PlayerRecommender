The purpose of this app is not functional — it is still in development, with more features and tools to be added and integrated. This is just a demo to show basic skills.

## Overview

This is an NBA-based app that lets you see the stats of players and teams. A future version will let you get player recommendations that suit team needs and certain archetypes.

## Tools Used

- Python
- Django
- SQLite
- Kaggle CSV datasets (player career, season, per-game, shooting, and totals stats)
- Django ORM
- Git / GitHub
